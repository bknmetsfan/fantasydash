## Gotchas (new this session; older ones in 09-15)
- Sleeper files waiver claims under the week they were *placed*; the board must use the
  week they were *for* (`week_of(ts)`). Otherwise streamer QBs show projection 0.
- `fa_snapshots` only contains players on the board at snapshot time; players already
  rostered when a bid is examined get their context from `backfill_board()`, which
  rebuilds rosters-minus-adds-plus-drops for that run.
- `Lock.acquire(blocking=False, timeout=…)` raises `ValueError` — bit us once.
- Flask test client is not thread-safe; don't test the lock with threads that way.
- `pending_chop` (CONFIG) is the only way a manual-elimination league (Degenerates)
  gets a chop pool; nothing is inferred from scores any more.
- Symptom "site won't load, /healthz times out, machine `started`, check `critical`":
  a build is hung upstream. `flyctl machine restart` alone won't fix it if the first
  request re-hangs; the timeout/non-blocking fix should, but check `flyctl logs` for
  a traceback in `current_state`.
